# 09_five_book_geographic_route.md

**BOOK I (North & Northwest):** Barcelona -> Balearic Sea -> Gulf of Alghero -> Grotta di Nettuno -> Alghero -> Argentiera -> Porto Torres -> Sassari -> Castelsardo -> Bosa.
**BOOK II (West Corridor):** Bosa -> Macomer -> Santu Antine (Torralba) -> Nuraghe Losa (Abbasanta) -> Pozzo di Santa Cristina (Paulilatino) -> Sinis Peninsula (Tharros) -> Cabras -> Oristano -> Monte Arci. (Corrected southward linear route to prevent backtracking).
**BOOK III (Southwest & South):** Monte Arci -> Iglesias -> Carbonia (Serbariu) -> Porto Flavia -> Sant'Antioco -> Pula (Nora) -> Cagliari.
**BOOK IV (South Central & East):** Cagliari -> Barumini (Su Nuraxi) -> Giara di Gesturi -> Ulassai -> Baunei -> Golgo Plateau (Su Sterru).
**BOOK V (Barbagia & Northeast):** Baunei -> Gola di Gorropu -> Dorgali (Tiscali) -> Orgosolo -> Mamoiada -> Ottana -> Nuoro -> Bitti (Romanzesu) -> Olbia. 
*(Epilogue / Reserve):* Capo Testa, La Maddalena, Tavolara.
