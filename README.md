## 📖 Overview

The **Sardinia Saga Engine** (also known as *The Book Brain*) is a specialized software environment designed to manage, audit, simulate, and render the complete narrative ecosystem of the *Sardinia Saga*. It enforces strict fail-closed continuity rules, zero-invention research firewalls, mineralogical authenticity, and automated multi-inspector review swarms.

### Key Features

* **Immutable 12-Chapter Book I Baseline**: Byte-locked narrative text (`BOOK_01_C01` through `BOOK_01_C12`) totaling **47,822 narrative prose words** (330,251 bytes), verified via SHA-256 byte receipts.
* **Amulet Nexus & Custody Engine**: Tracks the 12 true Sardinian amulets (mineral type, acquisition challenge, activation condition, cost, limitation, and false decoy detection).
* **Master Route Atlas & Lore Explorer**: Real-time GIS routing and heritage registry covering Nuraghi, Domus de Janas, karst caves, giants' tombs, medieval towers, and UNESCO tentative sites.
* **20-Inspector Swarm Audit Engine**: 20 independent domain auditors with exact-quotation provenance and hash binding.
* **Fail-Closed State Machine**: 11-step pipeline ensuring no chapter is advanced, published, or certified without 100% inspector consensus and human sign-off.
* **ChatGPT & Gemini API Bridge**: Embedded REST API (`POST /api/bridge/audit`) and OpenAPI 3.0.3 specification (`/openapi_gemini_bridge.json`) for external GPT Actions and server-side Gemini Flash calls.
